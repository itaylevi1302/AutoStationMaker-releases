# AutoStationMaker

**BlueBird UAV Systems** — Ground Control Station deployment automation tool.

AutoStationMaker automates the creation of BBGCS station packages for TBVT, WBVT and SpyX UAV systems.

## Download

| File | Description |
|------|-------------|
| `AutoStationMaker_Setup_2.0.0.exe` | Full installer — recommended |
| `AutoStationMaker2.0.exe` | Standalone EXE |

See the [Releases](../../releases) page to download the latest version.

## Requirements

- Windows 10/11 (64-bit)
- Administrator privileges (UAC elevation requested automatically)
